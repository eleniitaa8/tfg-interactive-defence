# TFG Interactive Defence

Interactive iPad companion for the presentation and defence of the Biotechnology Final Degree Thesis:

**Functional Validation of Candidate Tumour-Reactive Antigens Identified by the Upscale Screening Platform**

The app is designed as a touchable scientific workflow, not as a replacement for the oral presentation. It allows the tribunal to explore the project visually while the presentation is ongoing and during questions.

## Main goal

To communicate the project as one connected biological and experimental system:

**tumour antigen source → antigen tiles → peptide–HLA presentation → TCR recognition → Upscale screening → candidate prioritisation → individual validation → TYR-associated recognition**

## Scientific message

The project supports **candidate-tile-level TYR-associated recognition**, especially for **TCR60**, with additional support for **TCR572** and **TCR31**.

The app must remain conservative: it should not imply that the minimal peptide epitope, HLA restriction element or endogenous tumour contribution have been resolved.

## Design principles

- Landscape layout for 13-inch iPad
- White background
- Elegant biotech / clean academic aesthetic
- Simple schematic icons
- Touch-friendly
- Smooth but subtle animations
- Minimal text
- Conservative scientific interpretation
- No GEMIN5 branch
- No future prospects section
